## 📋 نظرة عامة على المشروع

تم تطوير هذا المشروع لأغراض تعليمية وبحثية تقنية. وهي أداة واجهة أمامية خفيفة مصممة لمساعدة المطورين والطلاب على فهم كيفية استخراج البيانات الوصفية المهيكلة من صفحات إف سي 2 المتاحة للعامة (FC2 Video، FC2 Blog، إلخ)، باستخدام واجهات معاينة الويب القياسية وواجهات برمجة التطبيقات للبيانات المهيكلة.

> 🎯 حالات الاستخدام الموصى بها:
> - تنظيم مواد الدراسة الشخصية وجمع الأفكار
> - ممارسة تطوير الواجهات الأمامية والبحث في استخراج بيانات الويب
> - التعلم حول هياكل البيانات الوصفية للوسائط المتعددة
> - أرشفة المحتوى المتاح للعامة بموافقة صريحة من أصحاب حقوق النشر

⚠️ **تنويه مهم**: تعمل هذه الأداة حصريًا مع **المحتوى المتاح للعامة** عبر ميزة معاينة الويب في إف سي 2. لا تهدف ولا تمكّن من الوصول إلى المحتوى الخاص، أو المحتوى الذي يتطلب تسجيل الدخول، أو المحتوى المدفوع/المميز، أو أي محتوى ذي قيود وصول.

## ✨ الميزات الرئيسية

- 🔗 **التعرف الذكي على الروابط العامة**: يكتشف تلقائيًا عناوين URL للمحتوى العام على إف سي 2 (`video.fc2.com`، `blog.fc2.com`، إلخ)
- 🎬 **دعم تنسيقات متعددة**: يستخرج البيانات الوصفية لفيديوهات وصور وملفات صوتية وملفات وسائط أخرى متاحة للعامة (يجب أن يكون المحتوى مضبوطًا على وضوح الرؤية العام)
- 📐 **عرض معلومات أساسية**: يُظهر نوع الوسائط، وحجم الملف، وطابع زمني للتحميل، ومعلومات المؤلف، وغير ذلك من البيانات الوصفية المتاحة للعامة
- 📱 **تصميم متجاوب بالكامل**: تجربة مستخدم محسّنة لأجهزة سطح المكتب والأجهزة اللوحية والهواتف المحمولة
- ⚡ **هندسة تعتمد على جانب العميل أولاً**: يتم تنفيذ منطق التحليل الرئيسي في المتصفح، مما يقلل من اعتمادية الخادم ويحسن سرعة الاستجابة
- 🔐 **تصميم يحترم الخصوصية**: لا يسجل عناوين URL المرسلة، ولا يخزن نتائج التحليل، ولا يجمع أي بيانات شخصية للمستخدمين أو معلومات الحساب

- استخدام هذه الأداة للوصول إلى، أو توزيع، أو نشر محتوى ينتهك الخصوصية، أو القوانين، أو حقوق الملكية الفكرية

## 🛠 ملاحظات التنفيذ التقني (للمطورين)

> يمكن للمستخدمين العاديين تخطي هذا القسم

### نظرة عامة على الهندسة
```
متصفح المستخدم → وحدة التحليل من جانب العميل → صفحة إف سي 2 العامة / واجهة OEmbed → استخراج البيانات المهيكلة → عرض النتائج
```

### النهج التقنية الرئيسية
- يستخدم واجهة برمجة التطبيقات `fetch` مع تكوين وكيل CORS مناسب لاسترداد البيانات الوصفية من صفحات معاينة الويب العامة
- يحلل علامات Open Graph (`og:video`، `og:image`، `og:title`، إلخ) لاكتشاف روابط الموارد
> يستفيد من البيانات المهيكلة (JSON-LD / Microdata) من صفحات المعاينة لاستكمال معلومات الوسائط
- يطبق التحقق المزدوج عبر أنماط التعبيرات النمطية + تحليل DOM للتعرف القوي على الروابط

### دليل الاستضافة الذاتية (مرجع)
```bash
# 1. استنساخ المستودع (مثال)
git clone https://github.com/yourname/fc2-downloader-ar.git

# 2. نشر الملفات الثابتة (يُوصى بشدة باستخدام HTTPS)
#    - Vercel / Netlify / Cloudflare Pages (إعداد سهل، موصى به)
#    - Nginx + شهادة Let's Encrypt (خيار الاستضافة الذاتية)

# 3. مثال تكوين رؤوس الأمان (Nginx)
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline';";
add_header X-Content-Type-Options "nosniff";
add_header Referrer-Policy "strict-origin-when-cross-origin";
add_header X-Frame-Options "DENY";
```

> 🔐 أفضل الممارسات للنشر في بيئة الإنتاج:
> - مكن دائمًا من HTTPS لمنع هجمات الرجل في المنتصف
> - نفذ تحديد معدل الطلبات (rate limiting) لمنع إساءة الاستخدام والطلبات المفرطة
> - تجنب تعريض منطق التحليل الحساس الذي قد يُساء استخدامه
> - راجع وحدّث التبعيات بانتظام لتطبيق تصحيحات الأمان

## ❓ الأسئلة الشائعة (FAQ)

**س: لماذا تظهر رسالة "تعذر جلب المحتوى"؟**  
ج: الأسباب المحتملة: ① يشير الرابط إلى محتوى خاص أو يتطلب مصادقة أو محتوى مدفوع/مميز ② تم حذف المحتوى أو ضبطه كـ "لأعضاء فقط" ③ غيّر إف سي 2 هيكل معاينة الويب مؤقتًا ④ قيود الشبكة أو مشاكل CORS. الحل: التحقق من الحالة العامة → التجربة عبر شبكة مختلفة → الانتظار وإعادة المحاولة.

**س: هل يحتوي الفيديو/الصورة التي تم تنزيلها على علامات مائية؟**  
ج: تُرجع هذه الأداة عناوين URL الأصلية للموارد التي توفرها البنية التحتية الرسمية لـ إف سي 2. يعتمد وجود العلامات المائية كليًا على إعدادات المستخدم الذي قام بالتحميل. لا تضيف هذه الأداة أو تزيل أو تعدل أي علامات مائية أو علامات مضمنة.

**س: هل تدعم المعالجة المجمعة لسجل محتوى إف سي 2 Video/Blog؟**  
ج: يركز الإصدار الحالي على تحليل المحتوى الفردي لإعطاء الأولوية للاستقرار والامتثال التنظيمي. للعمليات المجمعة، يُرجى أولاً التأكد من أن حالة الاستخدام الخاصة بك تتماشى مع [شروط الخدمة](https://fc2.com/terms/) لـ إف سي 2 فيما يتعلق بحدود المعدل واستخدام البيانات.

**س: هل تجمع هذه الأداة بيانات الاستخدام الخاصة بي أو معلومات حساب إف سي 2؟**  
ج: لا. هذا مشروع واجهة أمامية ثابت بحت بدون تسجيل في الخلفية، أو نصوص تحليلات، أو تتبع يعتمد على ملفات تعريف الارتباط، أو ربط حساب. تتم جميع المعالجات محليًا ضمن جلسة المتصفح الخاصة بك، ولا يلزم تسجيل الدخول.

**س: هل يمكن تحليل المحتوى المدفوع أو الموارد الحصرية للأعضاء؟**  
ج: لا. تدعم هذه الأداة حصريًا **روابط معاينة الويب من الصفحات العامة**. لا يتم دعم تحليل المحتوى المدفوع، أو الموارد الحصرية للأعضاء، أو المحتوى الذي يتطلب تسجيل الدخول تقنيًا، وغير مُستحسن أخلاقيًا. يعكس هذا التزامنا الأساسي بخصوصية المستخدم وامتثال المنتج.
